Around 01:40–02:39, he distinguishes CSS tools, behavior libraries, and styled systems. This motivates separating styling from behavior and deciding how much style ownership the team wants.
- [shadcn customization/create discussion](https://www.youtube.com/watch?v=aKPaxQJs-30), 16 December 2025: code ownership and customization are central. Around 03:38–04:13, he discusses customizable choices rather than identical copied defaults. The demonstrated generator interface is a dated snapshot, not an installation manual.
- [Flaws of the T3 Stack](https://www.youtube.com/watch?v=-R9uHm0G5m4), around 06:43–07:49: historical Tailwind scanning and bundle concerns. Verify the installed major version before applying them.

The representative-component sequence, token integration rules, caller inspection, behavior contract, state checks, and completion criteria are adaptations. They have not been established as Theo's exact personal checklist. This skill does not assert that a particular current generator, primitive library, or CSS version has been runtime-tested.
